Model handover: the formats that outlive the software

A model is only as durable as the format it is handed over in. A native file tied to a specific software version is a hostage to that software’s future; in five years the owner may not have the licence, the version, or the vendor.

This is why handover should include open, durable formats alongside the native model — IFC for the geometry and data, structured exports for the asset information — so the record survives independent of any one tool. The owner inherits data, not a dependency.

It is also why the information, not just the geometry, has to be structured. A model that looks complete but whose asset data is locked in proprietary fields is a record that degrades the moment the software moves on.

We hand over in durable, open formats with structured data, so the digital record remains usable for the life of the asset, not the life of a software licence.
