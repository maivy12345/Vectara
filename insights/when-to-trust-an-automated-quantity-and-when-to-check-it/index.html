Extracting quantities from a model is fast and consistent, which is exactly why it can be over-trusted. The number the model produces is only as good as the model behind it; an element modelled wrong, double-counted or missing produces a confident quantity that is simply incorrect.

The discipline is to treat model quantities as reliable but verifiable. We reconcile them against the design intent, sense-check the big-ticket items, and investigate divergence rather than assuming the model is right because it is precise. Precision is not the same as accuracy.

Used this way, 5D quantities are a powerful tool: fast, traceable to their source elements, and auditable. Used uncritically, they automate errors at speed.

We pair automated take-off with reconciliation against the design, so the quantities are both fast and trustworthy — not just fast.
