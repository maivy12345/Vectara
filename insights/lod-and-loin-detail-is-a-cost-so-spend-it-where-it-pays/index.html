LOD and LOIN: detail is a cost, so spend it where it pays

  • Model standards
  • 2 min read
TopicModel standards
Reading time2 minutes
Share
LinkedInEmail
All insights ←

Two acronyms shape every BIM brief: Level of Development (LOD), how detailed the geometry is, and Level of Information Need (LOIN), what information is actually required. Confuse or ignore them and you either over-model — paying for detail nobody uses — or under-model and miss what the project needs.

The mature approach treats detail as a budget to be spent deliberately. An element at a coordination stage needs enough geometry to coordinate; an element at handover needs the asset data the operator will rely on. More is not better; appropriate is better.

Getting this right speeds coordination, shrinks files and makes handover usable. Getting it wrong produces a heavy, slow model that is simultaneously over-detailed and missing the information that matters.

We define LOD and LOIN per stage in the BEP, so the model carries the right detail in the right place — and the project pays for information it will actually use.
